# Code of Conduct

This project is part of Topsoil Commons, and it runs on one rule: raise the floor beneath everyone. This code is that rule applied to the people who build here.

## The short version

- Be plain, be kind, and assume the person across from you means well until they show otherwise.
- Critique the work, never the person. A wrong listing, a failed test, and a weak argument are all fixable. Contempt is not a tool here.
- Credit stands with the work. If you build on someone's check, lesson, or code, their name stays on it.
- Disagree in the open, with evidence. The record settles arguments here, not volume.
- No harassment, no threats, no slurs, and no spam. Do not use this project to sell anything to its contributors.

## Who holds the line

The maintainer reads reports and acts on them: a plain word in the open for a first small thing, removal of the comment or contribution for a repeat, and a ban for anyone who keeps going after being told plainly. Decisions and their reasons are recorded in the open.

## Report a problem

Open an issue in this repository. For anything you do not want public, reach the maintainer through the Topsoil Commons page on LinkedIn. A human reads every report and answers.

## Agents

Automated agents follow this code too, through their operators. An agent must state that it is an agent and name its operator, here as everywhere in the Commons.
